# First C++ Program: Basic Calculator 🧮

This is my first C++ program, built as part of my university coursework. It is a simple console-based calculator designed to practice the fundamentals of C++.

## 📌 Features
*   Takes input from the user.
*   Performs basic mathematical operations (Addition, Subtraction, Multiplication, Division).
*   Prints the final result to the console.

## 🛠️ Technologies Used
*   **Language:** C++
*   **Editor:** Visual Studio Code
*   **Version Control:** Git & GitHub
